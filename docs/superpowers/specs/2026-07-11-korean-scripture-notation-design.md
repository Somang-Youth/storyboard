# 한국어 장절 표기 파싱 설계

## 목표

말씀 입력에서 기존 콜론 표기뿐 아니라 한국어 `장`/`절` 표기를 인식한다. 예를 들어 `말씀: 로마서 10장 14~21절`을 기존 정규형인 `롬 10:14~21`로 변환한다.

## 지원 범위

- 성경 권은 기존과 동일하게 축약형과 풀네임을 모두 허용한다.
- 단일 절 `로마서 10장 14절`을 `롬 10:14`로 정규화한다.
- 같은 장 범위 `로마서 10장 14~21절`과 `로마서 10장 14-21절`을 `롬 10:14~21`로 정규화한다.
- 기존 콜론 표기와 장을 넘는 콜론 범위는 현재 동작을 유지한다.
- 장을 넘는 한국어 표기인 `10장 14절~11장 2절`은 이번 범위에 포함하지 않는다.

## 설계

`lib/scripture/notation.ts`에 순수 함수 `normalizeScriptureNotation`을 추가한다. 이 함수는 장절 문자열을 파싱하기 전에 공백을 허용하면서 `장`을 `:`로 치환하고 마지막 `절`을 제거한다. 변환된 문자열은 검증이 이미 구현된 기존 파서에 전달한다.

Discord 댓글 파서와 말씀 미리보기/PPT 파서가 같은 입력을 일관되게 처리하도록 양쪽 파싱 경로에서 이 정규화를 사용한다. 성경 권 매핑, 범위 순서 검증, 출력 형식은 변경하지 않는다.

두 파서 자체를 통합하거나 기존 성경 권 별칭 규칙을 바꾸는 작업은 이번 범위에 포함하지 않는다.

## 오류 처리

한국어 표기가 지원 패턴과 일치하지 않으면 억지로 변환하지 않고 기존 오류 처리에 맡긴다. Discord 정규화는 기존처럼 원문을 보존하고, 미리보기/PPT 파서는 기존 형식 오류를 반환한다.

## 테스트

- `말씀: 로마서 10장 14~21절`이 `롬 10:14~21`로 추출되는 회귀 테스트를 먼저 추가하고 실패를 확인한다.
- 단일 절 한국어 표기와 하이픈 범위를 검증한다.
- 미리보기/PPT용 참조 파서에서도 같은 한국어 표기를 검증한다.
- 기존 축약형·풀네임·콜론 표기 테스트 전체가 계속 통과하는지 확인한다.
